# 🌎 GeoAtlas

O GeoAtlas é uma aplicação multiplataforma para gerenciamento,
consulta e visualização de informações geográficas.

O projeto foi desenvolvido com finalidade educacional e demonstra
a construção de uma aplicação completa utilizando diferentes
tecnologias Web e Mobile sobre uma mesma base de dados.

## 🎯 Objetivo

Demonstrar, de forma prática, o desenvolvimento completo de uma
aplicação, desde a modelagem do banco de dados até a implementação
de diferentes interfaces Web e Mobile.

## 🗄️ Banco de Dados

SGBD: MySQL

Principais entidades:

- Continentes
- Países
- Cidades
- Governantes
- Usuários
- Logs
